ANTIDOTE SURVIVAL ONLINE - INSTALACION

1) Instala Node.js LTS desde nodejs.org
2) Abre esta carpeta en VS Code
3) Abre terminal y ejecuta:

   npm install
   npm start

4) Abre el juego en:

   http://localhost:3000

5) Para probar con amigos en la misma red:
   - Busca tu IP local con ipconfig
   - Ellos entran a http://TU-IP:3000

6) Para que funcione mundialmente hay que subirlo a Render/Railway/VPS.

Incluye:
- Juego en public/index.html
- server.js para chat global, equipos y top mundial
- data.json para guardar ranking/chat
